## 1 Spark SQL

### Создание таблиц и представлений
- **Временные представления (Temp View)**  
  `df.createOrReplaceTempView("table_name")` — живут в рамках текущей SparkSession.
- **Глобальные временные представления**  
  `df.createOrReplaceGlobalTempView("name")` — доступны между сессиями через `global_temp.name`, пока приложение запущено.
- **Перманентные таблицы**  
  `df.write.mode("overwrite").saveAsTable("catalog.db.table")` или SQL `CREATE TABLE ... USING ... LOCATION ...`. Требуют настроенного метастора (Hive Metastore или встроенный каталог).

### Интеграция с Hive Metastore
- Включается `.enableHiveSupport()` при создании `SparkSession`.  
- Позволяет работать с существующими таблицами Hive, использовать UDF и форматы SerDe.
- Настройка: `spark.sql.catalogImplementation` — `hive` (по умолчанию, если Hive в classpath) или `in-memory`.
- Таблицы Hive читаются через `spark.table("db.table")` или `spark.sql("SELECT ... FROM db.table")`.

### Выполнение SQL-запросов (`spark.sql`)
- `spark.sql("SQL-запрос")` возвращает DataFrame. Поддерживает SELECT, INSERT, CREATE, ALTER и т.д.
- Рекомендуется не подставлять переменные напрямую в строку, использовать f-строки с осторожностью (риск инъекций).

### Взаимодействие DataFrame и SQL
- DataFrame можно зарегистрировать как представление и использовать в SQL.
- Результат SQL можно дообрабатывать методами DataFrame API (filter, groupBy и т.д.).
- Кэширование: `spark.sql("CACHE TABLE ...")` или `df.cache()`.

### Встроенные функции (`pyspark.sql.functions` / `o.a.s.sql.functions`)
- **Строковые**: `upper`, `lower`, `trim`, `lpad`, `rpad`, `concat`, `concat_ws`, `split`, `regexp_replace`, `substring`, `instr`.
- **Математические**: `abs`, `round`, `ceil`, `floor`, `exp`, `log`, `pow`, `sqrt`, `sin`, `cos`.
- **Агрегатные**: `sum`, `avg`, `min`, `max`, `count`, `countDistinct`, `approx_count_distinct`, `stddev`, `variance`, `first`, `last`.
- **Условные**: `when`, `coalesce`, `ifnull`, `nanvl`, `nullif`.
- **Коллекции**: `size`, `array_contains`, `explode`, `posexplode`, `map_keys`, `map_values`.

### `cube`, `rollup`, `grouping sets`
- **ROLLUP (col1, col2)** — иерархические итоги: (col1,col2), (col1, NULL), (NULL, NULL).
- **CUBE (col1, col2)** — все комбинации: (col1,col2), (col1,NULL), (NULL,col2), (NULL,NULL).
- **GROUPING SETS ((col1,col2), (col1), ()))** — явный перечень группировок.
- Функция `grouping(col)` возвращает 1 для строк с обобщением по этому столбцу (полезно для фильтрации итогов).

**Пример**:
```python
from pyspark.sql.functions import grouping
df.cube("country", "city").agg(sum("sales"), grouping("country").alias("is_total_country"))
```


## 2 DataFrame API

### Базовые операции
- `select("col1", col("col2"))`, `selectExpr("col1 as c1")` — выбор колонок.
- `withColumn("new", expr)` / `withColumnRenamed` — добавление/замена.
- `drop("col")` / `drop("col1", "col2")`.
- `filter(cond)` / `where(cond)` — условия комбинируются через `&`, `|`, `~` (PySpark) или `&&`, `||`, `!` (Scala).
- `distinct()` и `dropDuplicates(["col1","col2"])` — удаление дубликатов.

### Агрегации: groupBy, agg, pivot
- `df.groupBy("key").agg(sum("val"), avg("val"))` — обычная агрегация.
- `df.agg(...)` — без группировки.
- **PIVOT** — разворот строк в столбцы:
  ```python
  df.groupBy("product").pivot("year", [2019,2020]).sum("revenue")
  ```
- Можно комбинировать с `rollup`/`cube`.

### Типы Join
- Внутренний (inner), левый внешний (left/left_outer), правый внешний (right/right_outer), полный внешний (full/outer).
- **Semi-join** (left_semi) — эквивалент EXISTS (не увеличивает количество строк).
- **Anti-join** (left_anti) — NOT EXISTS.
- **Cross join** — декартово произведение (использовать осторожно, часто с broadcast хинтом).
- Broadcast join: `df1.join(broadcast(df2), condition)`.

### Union, intersect, except
- `union(df2)` — по позициям колонок; для объединения по именам → `unionByName(df2, allowMissingColumns=True)`.
- `intersect(other)` — строки, присутствующие в обоих DataFrame.
- `except(other)` / `subtract` — строки, которые есть в первом, но нет во втором.

### Работа со сложными типами
#### StructType / StructField
- Вложенная структура: `struct("city", "street").alias("address")`.
- Обращение: `df.select("address.city")`, разворачивание: `df.select("address.*")`.

#### ArrayType
- `explode(array)` — создаёт по строке на элемент, `posexplode` добавляет индекс.
- `array_contains`, `size`, `element_at`.
- Функции высшего порядка через `expr`: `filter(array, x -> x > 2)`, `transform(array, x -> x * 2)`.

#### MapType
- `map_keys(map)`, `map_values(map)`, `explode(map)` — даёт столбцы `key` и `value`.
- Создание: `map_from_arrays(keys, values)`.

#### JSON
- **from_json** — парсинг JSON‑строки по схеме:
  ```python
  schema = StructType().add("id", IntegerType()).add("name", StringType())
  df.withColumn("data", from_json("json_str", schema))
  ```
- **to_json** — сериализация структуры в строку.
- **get_json_object** — извлечение по JsonPath (строка, медленнее).
- **json_tuple** — извлечение нескольких полей за один проход.
- **schema_of_json** — автоматическое определение схемы по образцу JSON.

### Обработка null-значений
- `fillna(value, subset)` — замена null; можно передать dict: `{"col1": 0, "col2": "unknown"}`.
- `dropna(how='any'/'all', thresh, subset)` — удаление строк с null.
- `replace(to_replace, value)` — замена конкретных значений.
- Функции:
  - `coalesce(col1, col2, ...)` — первое не‑null.
  - `ifnull(col, replacement)` — то же для двух.
  - `isnull(col)`, `isnan(col)`.
  - `when(cond, v).otherwise(v2)`.

### Оконные функции
Определение окна через `Window`:
```python
from pyspark.sql.window import Window
w = Window.partitionBy("dept").orderBy("salary")
```

#### Ранжирующие
- `row_number()`, `rank()`, `dense_rank()`, `percent_rank()`, `ntile(n)`.

#### Аналитические
- `lead(col, offset, default)`, `lag(...)` — сдвиг относительно текущей строки.
- `first_value(col)`, `last_value(col)` (для последнего значения необходим полный диапазон окна: `rowsBetween(Window.unboundedPreceding, Window.unboundedFollowing)`).

#### Агрегатные с окнами
- Сумма нарастающим итогом:
  ```python
  sum("amount").over(w.rowsBetween(Window.unboundedPreceding, Window.currentRow))
  ```
- `avg`, `min`, `max`, `count` также допустимы.


## 3 RDD API

### Трансформации (ленивые)
- **Element-wise**: `map`, `flatMap`, `filter`.
- **По партициям**: `mapPartitions`, `mapPartitionsWithIndex` — эффективны для инициализации ресурсов (подключение к БД).
- `glom()` — собирает партицию в массив.
- `sample(withReplacement, fraction)`.

### PairRDD
- Операции над парами (ключ, значение):
  - `groupByKey()` — осторожно, shuffle + возможен OOM; предпочтительнее `reduceByKey(func)` (map‑side combine).
  - `aggregateByKey`, `combineByKey` — гибкая агрегация.
  - `sortByKey()`.
  - Joins: `join`, `leftOuterJoin`, `rightOuterJoin`, `fullOuterJoin`, `cogroup`.

### Действия (запускают вычисление)
- `reduce(func)`, `fold(zero)(func)`, `aggregate(zero)(seqOp, combOp)`.
- **Возврат на драйвер**: `collect()`, `take(n)`, `top(n)`, `first()` — осторожно с объёмами.
- `count()`, `countByKey()`, `foreach(func)`, `foreachPartition(func)`.
- Сохранение: `saveAsTextFile(path)`, `saveAsObjectFile(path)`.

### Аккумуляторы и широковещательные переменные
- **Аккумуляторы** — агрегация по узлам (только добавление, драйвер читает):
  ```python
  acc = sc.accumulator(0)
  rdd.foreach(lambda x: acc.add(1))
  print(acc.value)
  ```
- **Broadcast переменные** — эффективная передача больших read‑only объектов:
  ```python
  bc = sc.broadcast(dict_ref)
  rdd.map(lambda x: bc.value.get(x))
  ```


## 4 Работа с датой и временем

### Парсинг
- `to_date(col, format=None)` (по умолч. `yyyy-MM-dd`).
- `to_timestamp(col, format=None)` (по умолч. `yyyy-MM-dd HH:mm:ss`).
- `unix_timestamp(col, format)` → секунды с эпохи.

### Извлечение компонентов
- `year`, `month`, `dayofmonth`, `dayofyear`, `weekofyear`, `quarter`.
- `hour`, `minute`, `second`.
- Гибкое форматирование: `date_format(col, "yyyy-MM-dd")`.

### Арифметика
- `date_add(date, days)`, `date_sub(date, days)`, `datediff(end, start)`.
- `add_months(date, months)`, `months_between(date1, date2)`.
- Выражения: `expr("date + interval 1 day")`.

### Временные зоны
- `from_utc_timestamp(ts, "Europe/Moscow")`, `to_utc_timestamp(ts, "Europe/Moscow")`.
- Сессионная зона: `spark.conf.set("spark.sql.session.timeZone", "UTC")`.


## 5 Пользовательские функции (UDF)

### UDF (PySpark)
```python
from pyspark.sql.functions import udf
from pyspark.sql.types import IntegerType
@udf(returnType=IntegerType())
def my_len(s):
    return len(s) if s else 0
```
Ограничения: черный ящик для Catalyst, высокая стоимость сериализации.

### UDAF (Scala/Java)
В Scala предпочтителен `Aggregator` (типизированный). В PySpark агрегации эмулируются через `collect_list` + UDF (медленно) или Pandas UDF.

### Pandas UDF
- Векторизованы через Apache Arrow, работают на pandas.Series.
- Синтаксис:
  ```python
  @pandas_udf('double')
  def mul(a: pd.Series, b: pd.Series) -> pd.Series:
      return a * b
  ```
- Итератор: `Iterator[pd.Series] -> Iterator[pd.Series]` для контроля над пакетами.

### Pandas Function APIs
- `groupby().applyInPandas(func, schema)` — пользовательская агрегация/обработка с pandas.
- `mapInPandas(func, schema)` — трансформация по партициям.

### Рекомендации
- Всегда предпочитать встроенные функции.
- Если нужна UDF, на JVM‑языке — на Scala/Java.
- В PySpark по возможности использовать Pandas UDF (десятки и сотни раз быстрее построчных UDF).


## 6 Дополнительные API

### JDBC
- Чтение: `spark.read.format("jdbc").option("url", ...).option("dbtable", "table").load()`.
- Параллелизация:
  - Через целочисленный столбец: `partitionColumn`, `lowerBound`, `upperBound`, `numPartitions`.
  - Через предикаты: `predicates = ["id < 100", "id >= 100 AND id < 200", ...]`.
- Производительность: настройка `fetchsize`, `batchsize`.
- Запись: `df.write.mode("append").jdbc(...)`.

### Avro и бинарные данные
- Формат Avro: `spark-avro` пакет. `format("avro")`.
- Schema Registry: параметры `avroSchema` или `from_avro` (Spark 3.0+).
- Бинарные колонки: чтение как `BinaryType`, манипуляции через UDF или `base64`.

### Статистические функции
- `df.summary()` — count, mean, stddev, min, 25%, 50%, 75%, max.
- `approxQuantile("col", [0.5], 0.01)` — медиана и другие квантили.
- `corr(col1, col2)`, `covar_samp(col1, col2)`.
- `crosstab("col1", "col2")` — таблица сопряжённости.
- `sampleBy("key", fractions, seed)` — стратифицированная выборка.
